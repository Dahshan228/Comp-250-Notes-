# The Limits of Certificate Revocation in Vehicle to Vehicle Communication

A research essay on a security gap in vehicle-to-vehicle (V2V) communication, revised as a plain-text, version-controlled document.

## About the essay

I wrote this essay in September 2026 for COMP-348 (Network Security) at Loyola University Chicago.
It argues that the Security Credential Management System (SCMS), which issues the certificates V2V messages depend on, cannot stop the first false message from a legitimate vehicle.
Certificates prove who sent a message but not whether it is true, and revocation only begins after misbehavior has been reported, reviewed, and distributed to other vehicles.

I revised the essay in COMP-250, converting it from a Word document to Markdown and recording every revision as a Git commit.
The commit history shows the revision step by step.

## Tools

- **Pandoc** converts the essay from DOCX to Markdown and builds the final DOCX, with citations and bibliography generated by `--citeproc`.
- **Git and GitHub** record each revision as a separate commit with a descriptive message.
- **Zotero with Better BibTeX** manages the sources and supplies stable citation keys, so no citation is typed by hand.
- **Citation Style Language** lets the citation style be changed with one line of metadata.

## Revision process

1. Converted the Word document to Markdown and put it under version control.
2. Moved the title, author, and course details into a YAML metadata block and added an abstract.
3. Put each sentence on its own line, so revisions show up as clean sentence-level diffs.
4. Added section headings and marked the context, problem, and claim of the introduction.
5. Replaced hard-coded citations with Zotero citation keys and let Pandoc generate the bibliography.
6. Reviewed each quotation for integration and commentary.
7. Revised the introduction and conclusion following Booth et al., *The Craft of Research* (5th ed., 2024), chapter 14.
8. Revised a body paragraph for clarity and flow using Booth et al.'s principles of characters as subjects, old before new, and complexity last.
9. Switched the citation style from Chicago author-date to APA.

## Building the essay

With Pandoc installed, run the command below in this folder.

```
pandoc eldahshan-v2v-essay.md --citeproc -o essay.docx
```

The Markdown file is the source of truth. Generated DOCX files are treated as disposable and are not committed.
