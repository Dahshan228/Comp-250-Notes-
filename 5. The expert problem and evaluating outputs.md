# Title
The Expert problem and Evaluating Outputs
# Summary

AI is best to use on tasks where the user already has existing knowledge on the subject. In these scenarios, the user can quickly identify errors and evaluate the quality of the AI's output, but if you where to rely on it to perform the deep intellectual work that builds experiance in the first place then it would be counterproductive.

# Evidence

“AI is often most useful where we're already expert enough to spot its mistakes, yet least helpful in the deep work that made us experts in the first place.”

# Citation

Mollick, Ethan. "15 Times to Use AI, and 5 Not To." One Useful Thing.
